# 3D Dice

A single-file 3D dice roller built with vanilla [Three.js](https://threejs.org/) (loaded from CDN).

- Drag to spin the die · tap it or press **Space** to roll
- No build step, no dependencies — just `index.html`

## Run locally

Open `index.html` in a browser, or serve the folder:

```powershell
npx serve .
```

## Deployment

Hosted on **Vercel**: every push to `main` auto-deploys to production.

```powershell
vercel --prod --yes   # manual deploy (optional)
```
